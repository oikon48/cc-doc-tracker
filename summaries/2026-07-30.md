### 既存ページの主要な変更

#### Desktop アプリ（重要な新機能）
**URL:** https://code.claude.com/docs/en/desktop.md

**「Work across sessions」セクションを新規追加。**

- Claudeが現在のセッションから他のDesktopセッションを一覧・確認・メッセージ送信・アーカイブできるようになった
- 対象はDesktopアプリで起動したローカル・SSH・WSLセッションのみ（クラウドセッション・CLI・VSCode拡張は除外）
- セッションをまたいだメッセージ送信時、受信セッションにはカードで通知が表示される
- **安全対策:** セッションアーカイブ前は常に確認プロンプトを表示（Auto・Bypass permissionsモードでも）、スケジュールタスク実行中のセッションへの送受信は不可
- Claudeが現在のタスクのスコープ外の問題を発見したとき、タスクチップとして新セッション開始を提案できる
- **Bypass permissions モード**の説明を更新：デスクトップ操作（セッションアーカイブなど）は常に確認が必要という例外を追記

#### エラーリファレンス（新しい警告の追加）
**URL:** https://code.claude.com/docs/en/errors.md

**新セクション「Is not matched by file permission checks」を追加。**

- `Write(path)`、`NotebookEdit(path)`、`MultiEdit(path)`、`Glob(path)` の形式でパーミッションルールを書いた場合、Claude Codeはルールを受け入れるが実際には照合されないことを警告
- 代わりに `Edit(path)` または `Read(path)` を使うよう誘導
- バックグラウンドセッションや `--output-format json` 使用時はデバッグログに書き込まれる（v2.1.210以降）

#### ルーティン（ブランチプッシュルール変更）
**URL:** https://code.claude.com/docs/en/routines.md

**ブランチプッシュの制御が変更:**

従来: ルーティンフォームの「Allow unrestricted branch pushes」設定で制御  
変更後: `claude/` プレフィックスのブランチへのプッシュは常に許可。それ以外のブランチは以下のいずれかに該当する場合はプッシュ拒否：
- GitHubで保護されたブランチ
- 他のユーザーからのオープンなPRがあるブランチ
- 自分以外のユーザーのコミットがあるブランチ

また、ルーティン作成フォームの「Permissions」タブが廃止され「Review connectors」のみとなった。

#### パーミッション（ファイルパーミッションルールの説明改善）
**URL:** https://code.claude.com/docs/en/permissions.md

- `Write`・`NotebookEdit`・`Glob`・`MultiEdit` のパスルールに関する説明を更新
- ファイルパーミッションチェックは `Edit(path)` と `Read(path)` のみを参照することを明確化
- エラーリファレンスへのリンク追加

#### サブエージェント（セキュリティ強化）
**URL:** https://code.claude.com/docs/en/sub-agents.md

- **エージェント名に `:` を使用不可**（v2.1.218以降）：プラグインのネームスペース区切り文字として予約済み。名前に含む場合はファイルを読み込まずデバッグログにエラーを出力
- **frontmatterフックにワークスペーストラスト要件追加**（v2.1.218以降）：プロジェクトレベルのサブエージェントのhooksを実行するにはワークスペーストラストダイアログの承認が必要。承認前でもサブエージェント自体は実行されるが、hooks はスキップされる

#### ヘッドレスモード・SDK連携（サブエージェントストリーミングの改善）
**URL:** https://code.claude.com/docs/en/headless.md

- **「Follow subagent messages」セクションを新規追加：** ネストされたサブエージェント（深度2以上）のメッセージがstream-json出力に含まれるようになった（v2.1.219以降、`--forward-subagent-text` フラグ使用時）
- **「Fail CI when a plugin or MCP server doesn't load」セクションを新規追加：** `system/init` イベントの `mcp_server_errors` フィールドでMCPサーバーの設定バリデーションエラーを検出できる（v2.1.219以降）
- capabilities配列に `interrupt_cancel_queued_v1` を追加
- Agent SDKのストリーミング出力ドキュメントへのリンクを追加

#### プラグインマーケットプレイス（組織向け配布ルールの明確化）
**URL:** https://code.claude.com/docs/en/plugin-marketplaces.md

- **組織向け配布（Organization settings > Plugins）のルールを明記：**
  - マーケットプレイスリポジトリは非公開または内部リポジトリであること
  - `npm` ソースは非対応
  - 同一オーナーのgithub.comリポジトリまたはGHEアプリが導入されたリポジトリのみ非公開プラグインを利用可能
- **`strictKnownMarketplaces: []`（空配列）の動作を明確化：** 公式Anthropicマーケットプレイスも含めてすべてをブロック（従来の説明では不明確だった）
- 公式Anthropicマーケットプレイスのみを許可する例を新規追加
- `ref` と `path` の一致ルールを改善（片方のみ指定する場合のルールを明確化）
- 「Private repositories」セクションを「Commands you run」と「Background auto-updates」に分割して説明を改善
